Guarded Adaptation & Anti-Contamination

Standard adaptive baselines suffer from contamination bias: when a true persistent anomaly occurs, updating rolling buffers on anomalous values corrupts reference statistics.

if is_anomalous: quarantine_buffer.hold(x_t)
else: rolling_reference_buffer.append(x_t)
